Báo cáo tiến độ và lập kế h oạch 10 ngày tới 1. Chi tiết các tính năng hiện có Kiến trúc &amp; Hạ tầng (Thiện): Đã hoàn thiện khung Clean Architecture với BLoC. Hệ thống Dependency Injection (DI) đã sẵn sàng để quản lý các Service. Luồng điều hướng (GoRouter) đã phủ khắp các màn hình chính và có lớp bảo vệ đăng nhập (Auth Guard). Giao diện &amp; UI Components (Huy): Hệ thống Design System (Màu sắc, Font, Spacing) đã đồng nhất. Đã có các Widget phức tạp: Trình phát Video, Code Editor với Syntax Highlighting, và các thẻ quản lý dung lượng bộ nhớ. Tính năng người dùng (Gia): Đã xong luồng Đăng ký/Đăng nhập với Firebase. Giao diện danh sách bài học, chi tiết lộ trình học (Module Overview) và khu vực thực hành (Learning Workspace) đã có khung hoàn chỉnh. Hệ thống lưu trữ: Đã tích hợp Isar Database để sẵn sàng cho tính năng học Offline. 2. Chi tiết các tính năng còn thiếu hoặc chưa hoàn thiện Hệ thống quản trị ( Tấn ): Thiếu bộ công cụ CMS trên Web Admin để upload video, soạn thảo bài học và quản lý mã nguồn mẫu. Dữ liệu thực tế (Thiện &amp; Gia): Các Repository vẫn đang trả về dữ liệu ảo (Mock), chưa kết nối với cơ sở dữ liệu thật. Logic nâng cao (Gia): Hệ thống lưu tiến độ học tập (Progress Tracking), đếm Streak (chuỗi ngày học) và tính điểm XP chưa hoạt động. AI Integration (Gia/Thiện): Chưa có tính năng tự động tạo Quiz từ nội dung bài học thông qua Gemini AI. Vận hành hệ thống (Thiện): Chưa có logic đồng bộ dữ liệu (Sync) giữa máy và Cloud; chưa có Download Manager chạy ngầm (Background) trên Kotlin. 3. Chi tiết các bug, lỗi và vấn đề tồn đọng Lỗi API 404 (Nghiêm trọng nhất): App không thể kết nối tới Server do các Endpoint trên Web Admin chưa được cấu hình hoặc sai đường dẫn. Điều này gây ra lỗi &quot;Không tìm thấy dữ liệu&quot; khi vào các trang chính. Vấn đề Mocks: App đang sống bằng dữ liệu giả, cần thay thế bằng dữ liệu thật từ phía Web Admin. Lỗi hiển thị (UX): Màn hình học tập bị tràn (Overflow) hoặc che khuất nội dung khi xoay ngang (Landscape) để xem Video. Hiệu năng: Trình soạn thảo Code bị lag khi xử lý các đoạn mã dài trên 500 dòng. Bảo mật: Quy tắc truy cập (Rules) trên Firebase chưa được thiết lập chặt chẽ. 4.
